## ⚙️ n8n Email Automation Engine

<div align="center">

### 📧 Lead → Template → Email → Log → State → Delay → Next Step

</div>

A marketing automation engine built using **n8n + Google Sheets** to simulate the core workflow of email automation platforms.

```text
                    NEW LEAD
                       │
                       ▼
                Load Template
                       │
                       ▼
                  Send Email
                       │
             ┌─────────┴─────────┐
             ▼                   ▼
         Log Event          Update State
             │                   │
             └─────────┬─────────┘
                       ▼
                     Wait
                       │
                       ▼
                  Next Email
```

### What it handles

📧 Multi-step drip campaigns  
📝 Dynamic email templates  
👤 Lead-state tracking  
⏳ Scheduled delays  
📊 Automation logging  
❌ Failure monitoring  
📑 Google Sheets integration  
📤 SMTP delivery
